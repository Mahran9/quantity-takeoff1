# حصر الكميات — Quantity Takeoff (v8.11.1)

تطبيق عربي يعمل بالكامل داخل المتصفح (بدون خادم) لمراجعة وحصر الكميات من مخططات PDF وDXF والصور، وتسعيرها وإخراج **عرض سعر** جاهز للطباعة على ورق شركتك أو للتصدير إلى Excel.

> الكميات المستخرجة آلياً **مساعدة تقديرية** وتتطلب مراجعة مهندس مختص قبل اعتمادها.

## التشغيل
```bash
npm install
npm run dev          # تطوير
npm run lint         # فحص الأنواع
npm run test:all     # كل الاختبارات
npm run build        # نسخة الإنتاج في dist/ (ملفات ثابتة + PWA)
```
النشر: ارفع محتوى `dist/` على أي استضافة ملفات ثابتة تعمل بـ HTTPS (Netlify/Vercel/Cloudflare Pages/GitHub Pages…).

## قراءة المخططات والتحقق منها (الأهم)
- **PDF المتجه**: يقيس الخطوط والأشكال ويجمعها حسب الطبقة أو اللون والسُمك. المجموعات المجهولة اقتراحات للمراجعة ولا تُضاف تلقائياً لمجرد تشابه اللون أو الشكل؛ عيّن نوعها (طول/مساحة/عدد) في «قياس وأدوات متقدمة».
- **المقياس**: يُقرأ من نص اللوحة (1:100) **ويُتحقق منه بمطابقة أرقام الأبعاد المكتوبة مع أطوال الخطوط المرسومة**؛ عند التعارض يحذّر ولا يسمح بالاستيراد قبل تأكيدك. يمكن المعايرة يدوياً بطول عنصر معروف.
- **معاينة بصرية**: خريطة للخطوط المقروءة مع إبراز المجموعة المحددة وما أُضيف للحصر.
- **الأرقام المطبوعة**: OCR عربي/إنجليزي يلتقط بعض المساحات والكميات المكتوبة والجداول. لا يحوّل كل مخطط ممسوح إلى حصر كامل؛ استخدم المعايرة والقياس اليدوي للبنود التي لا توجد كميتها مطبوعة.
- **DXF**: ترميز عربي (CP1256/UTF-8)، الطبقات المجمدة/المطفأة، المكرر، الوحدات، البلوكات. وتظهر لوحة تدقيق (أخضر/أصفر/أحمر) وتمنع الاستيراد عند الشك إلى أن تؤكد.
- **DWG** و DXF الثنائي غير مدعومين: صدّرهما DXF نصي أو PDF.
- **تحقق بنفسك على ملفاتك الحقيقية قبل الاعتماد**:
```bash
npx tsx scripts/verify-pdf.ts plan.pdf --expected expected.json   # PDF.js الحقيقي
npx tsx scripts/verify-dxf.ts drawing.dxf --expected expected.json # dxf-parser الحقيقي
```
ضع في `expected.json` أطوالاً/مساحات تعرفها (مثل طول جدار أو مساحة غرفة)؛ يفشل الأمر إن اختلفت أكثر من 2%.

## بياناتك
- كل المشاريع والمخططات والإعدادات محفوظة في **IndexedDB داخل متصفح المستخدم**، ولا يُرسل شيء لأي خادم.
- لذلك مسح بيانات المتصفح يحذف المشاريع. التطبيق يطلب تخزيناً دائماً، ويذكّر بأخذ نسخة احتياطية، ويحذّر عند امتلاء المساحة أو فشل الحفظ.
- النسخ الاحتياطي: شاشة «المشاريع» ← تصدير JSON. الاستيراد يتحقق من البنية ويرفض الملفات الأحدث من التطبيق.
- الانتقال من إصدار 5.x: صدّر نسخة JSON من كل مشروع في الإصدار القديم ثم استوردها هنا (التخزين الجديد منفصل عن القديم).

## هوية الشركة
لا يحتوي التطبيق على أي اسم شركة أو شعار ثابت. من زر الإعدادات (⚙) يدخل كل مستخدم: اسم الشركة، الرقم الضريبي، الشعار، **الورق الرسمي (صورة A4)**، الختم، الشروط والأحكام. تظهر في عرض السعر المطبوع وملف Excel فقط.

## عرض السعر
- أقسام حسب تسلسل التنفيذ في الموقع مع إجمالي فرعي لكل قسم، ثم الإجمالي والضريبة والإجمالي الكلي.
- نفس الأرقام على الشاشة والطباعة وExcel (البنود «المرفوضة» لا تدخل أي رقم).
- عربي أو إنجليزي، وبدون صفوف أو أعمدة فارغة في Excel.
- الطباعة إلى PDF: «طباعة / حفظ PDF» ← «حفظ كـ PDF» وفعّل «الرسومات الخلفية».

## قيود معروفة
- واجهة التطبيق بالعربية فقط حالياً.
- طباعة PDF تعمل في المتصفحات؛ داخل غلاف Android (Capacitor) قد لا تعمل — استخدم Excel أو المتصفح.
- PDF بلا طبقات ينتج مجموعات بحسب اللون/السُمك فقط؛ إن رُسمت البلاطة والقواعد بنفس اللون فستكون في مجموعة واحدة (استخدم تصنيف «عدد» بحسب مقاس الشكل). أسطح مغلقة متداخلة تُحسب مساحتها كلٌّ على حدة (راجع التداخل).
- تصنيف طبقات DXF يعتمد على الأسماء؛ استخدم «قواعد الطبقات» لتخصيصه لمكتبك.
- كشف الجدران المرسومة بخطين متوازيين يدوي (خيار في نافذة الاستخراج).
- ملفات DXF ثلاثية الأبعاد (3DFACE/MESH) غير مدعومة.
- الخط Cairo يُحمَّل من Google Fonts؛ بدون إنترنت يُستخدم خط النظام.

## Android (اختياري)
```bash
npm install -D @capacitor/cli @capacitor/core @capacitor/android
# غيّر appId في capacitor.config.ts إلى معرّفك
npm run build && npx cap add android && npx cap sync android && npx cap open android
```

## قائمة ما قبل النشر
1. غيّر `appId` في `capacitor.config.ts` واسم الحزمة/الوصف في `package.json` و`public/manifest.json` حسب علامتك.
2. اختر رخصة للمشروع وأضف ملف LICENSE (المكتبات المستخدمة: React, PDF.js, SheetJS, Tesseract.js, dxf-parser — راجع رخصها).
3. اختبر على جوال حقيقي: رفع PDF كبير، DXF، حفظ/استرجاع، الطباعة.
4. فعّل HTTPS وسياسة خصوصية قصيرة تذكر أن البيانات محلية.
